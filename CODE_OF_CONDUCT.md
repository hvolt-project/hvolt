# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be direct about the work and respectful to the people. Technical disagreement is welcome;
personal attacks, harassment and discriminatory language are not. Maintainers may edit, close or
reject contributions that do not meet this standard, and may block accounts that repeatedly do not.

## Scope

Issues, pull requests, discussions and any other project space.

## Reporting

Report a problem to the maintainers through the repository's issue tracker (open an issue marked
"conduct") or, if the report involves a security concern, through the private channel described in
[SECURITY.md](SECURITY.md). Reports are handled confidentially; the maintainers will respond as
quickly as they can and explain what action, if any, was taken.
